# Tic-Tac-Toe AI Using Java

## Project Overview

Tic-Tac-Toe AI is a Java-based game developed as part of an Artificial Intelligence internship. It allows a human player to compete against a computer opponent that uses the **Minimax Algorithm** to evaluate possible moves and select the best move based on potential game outcomes.

The game follows standard Tic-Tac-Toe rules on a 3×3 grid. Players take turns marking cells with X and O. A player wins by aligning three marks horizontally, vertically, or diagonally. If all cells are filled without a winner, the game ends in a draw.

## Features

- **Interactive Gameplay:** Play Tic-Tac-Toe against the computer.
- **AI-Based Decision Making:** Uses the Minimax Algorithm to evaluate possible moves.
- **Win and Draw Detection:** Identifies winning conditions and draw situations.
- **Game Board Display:** Shows the current board and game results.
- **Strategic Computer Opponent:** Selects moves based on possible game outcomes.

## Technologies Used

- **Programming Language:** Java
- **Artificial Intelligence:** Minimax Algorithm
- **Core Concepts:** Recursion, game logic, and Object-Oriented Programming

## How It Works

1. The game displays a 3×3 Tic-Tac-Toe board.
2. The human player selects a move.
3. The computer evaluates available moves using the Minimax Algorithm.
4. The AI selects its best move based on the possible outcomes.
5. The game continues until a player wins or the match ends in a draw.

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed.
- A Java IDE or terminal.
- Basic knowledge of running Java programs.

### Installation and Execution

1. Clone or download this repository.
2. Open the project folder in your preferred Java IDE or terminal.
3. Compile the main Java source file:

   ```bash
   javac TicTacToeAI.java
   ```

4. Run the program:

   ```bash
   java TicTacToeAI
   ```

5. Follow the on-screen instructions to play the game.

*Note: Replace `TicTacToeAI.java` with your actual Java filename if it differs.*
